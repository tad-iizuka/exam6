# mini_db 課題

**課題名**: mini_db
**提出ファイル**: `*.cpp` `*.hpp`

---

ポート番号とファイルパスを引数として受け取るプログラムを作成せよ。
プログラムは、指定されたポートで 127.0.0.1 におけるクライアントの接続を待ち受けなければならない。

プログラムが接続の受け入れ準備が整ったとき、標準出力に "ready\n" を出力すること。

プログラムは接続されたクライアントからコマンドを受け取り、キーとバリューのデータベースを維持する。

接続は永続的である。つまり、1つのセッションで複数のコマンドを送信できる。

## コマンド一覧

### POST

- **書式**: `POST <key> <value>`
- **説明**: db にエントリを追加する
- **戻り値**: `"0"`

### GET

- **書式**: `GET <key>`
- **説明**: db からエントリを取得する
- **戻り値**: `"0 <value>"`、キーが存在しない場合は `"1"`

### DELETE

- **書式**: `DELETE <key>`
- **説明**: db のエントリを削除する
- **戻り値**: キーの削除に成功した場合は `"0"`、キーが存在しない場合は `"1"`

コマンドが認識できない場合は `"2"` を返さなければならない。

キーとバリューは任意のサイズで、空白文字は含まれない。ただし、リクエストのサイズは1000文字を超えることはない。

プログラムは効率的でなければならない。

## データの永続化

プログラムが `SIGINT` シグナルを受け取ったとき、その時点のデータベース(すべてのキーとバリューのペア)を、引数として与えられたファイルパスに保存し、終了しなければならない。

プログラムが起動するたびに、このファイルの存在を確認し、あれば読み込むこと。

**ヒント**: nc(netcat)を使ってプログラムをテストできる。

このディレクトリには、ネットワークコードの使い方を忘れた場合のために、参考となるコードが含まれるファイルが用意されている。

## 実行例

```
$> ./mini_db 1111 .save &
$> nc localhost 1111 | cat -e
POST A B
0$
POST B C
0$
GET A
0 B$
GET C
1$
DELETE A
0$
DELETE C
1$
UNKNOWN_COMMAND
2$
^C
$> pkill -SIGINT mini_db
$> ./mini_db 1111 .save &
$> echo "GET B" | nc localhost 1111 | cat -e
0 C$
```
